# ✈️ Flight Delay Prediction System

A full-stack Machine Learning web application that predicts whether a flight will be **delayed or on-time** based on various flight and environmental factors.

---

## 🚀 Features

* 🔐 User Authentication (Login/Register)
* 📊 Flight Delay Prediction using ML Model
* 📈 Probability-based Results (Delay vs On-Time)
* 🧠 Smart Explanation System (Weather, Traffic, Previous Delay)
* 🗂️ User Prediction History
* 📩 Contact Form with Database Storage
* 👨‍💼 Admin Dashboard

  * View Users
  * View Messages
  * View Predictions

---

## 🛠️ Tech Stack

### Frontend:

### Backend:

* Python (Flask)

* SQLite

### Machine Learning:

* Scikit-learn (Random Forest Classifier)

---

## ⚙️ How It Works

1. User registers and logs in
2. Inputs flight details
3. Data is preprocessed
4. ML model predicts:

   * Delay Probability
   * On-Time Probability
5. Result is displayed with explanation

---

## 🧠 Machine Learning Details

* Algorithm: Random Forest Classifier
* Features Used:

  * Month, DayOfWeek, Distance
  * Airline, Origin, Destination
  * Weather, Traffic, Previous Delay
* Includes feature engineering & one-hot encoding
